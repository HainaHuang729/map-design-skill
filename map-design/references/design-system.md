# 设计参数与杭州示例

这些数值来自用户在2026-10-26认可的杭州地图，是起点，不是其他城市的固定配色或像素规范。

## 空间关系

| 元素 | 杭州参考值 | 调整要点 |
| --- | --- | --- |
| 桌面上方控件 | 距边18px，按钮42px，搜索宽300px | 地图持续占据主画面 |
| 手机上方控件 | 距边12–15px，按钮38px，搜索自适应 | 给右侧模式按钮留位置，考虑安全区 |
| 分类条 | 底部居中，约5项，暖白面板 | 手机保持一行可见，增加分类时重新评估布局 |
| 缩放控件 | 右下纵向排列，避开分类条 | 图标清楚，触摸范围约38–44px |
| 地点标记 | 图形约23px，按钮命中区44px | 图形小而轻，点选范围不能随之缩小 |
| 地点标签 | 桌面11px、手机10px | 可根据可读性增大；标签避让优先于强行缩字 |
| 介绍气泡 | 桌面最大252px，手机约232px | 窄屏保持边距，预留关闭、收藏和导航空间 |
| 圆角 | 控件5–8px，边线约1px | 保持轻巧，避免大面积重阴影 |

手机分类条与气泡要在320px窄屏检查。小号视觉文字仅作杭州密度参考；可根据语言、设备和用户需求放大，并重新调整密度。

## 杭州配色快照

| 用途 | 浅色 | 深色 |
| --- | --- | --- |
| 陆地 | `#f0f2e8` | `#26372f` |
| 林地 | `#dfe8d2` | `#304634` |
| 公园 | `#d2dfbd` | `#344b38` |
| 水面 | `#bbd8cc` | `#31574f` |
| 浮动面板 | `#fffef9` | `#26352e` |
| 主色 | `#356d63` | `#a5cbb9` |
| 桂花金强调 | `#aa792a` | `#dfbb70` |
| 正文 | `#293c35` | `#edf0e5` |
| 次要文字 | `#677969` | `#b1c2af` |
| 边线 | `#dce5d7` | `#475c4c` |

可复制 [配色变量](../assets/map-tokens.css) 后替换城市主题。文件只提供变量，不会生成整套界面。

配色由地形和当地印象组织：主色、水色、地形色、面板中性色以及少量强调色。比如湖城可以强调柔和水色，其他城市按自身特色另选；不将任何一种城市主题设为所有地图默认色。

浅色底图减弱道路、建筑和文字，保留湖岸、河网、山体与空间关系。深色使用对应的地形、水面与道路色，不能只切换面板。
